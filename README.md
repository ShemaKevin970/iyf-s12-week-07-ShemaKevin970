# Week 7 - Modern JavaScript Tooling

To-Do List + Shopping Cart built with ES Modules, localStorage, ESLint, Prettier, and Vitest.

## Features

- Add / toggle / delete todos, filter All / Active / Completed
- Dark mode, persists after refresh via localStorage
- Shopping Cart in `cart.html` - add, +/-, remove, total, persists
- Modular code: `state.js`, `storage.js`, `ui.js`, `utils.js`, `app.js`

## How to run

```bash
npm install
npm test
npm run lint
npm run format
```
